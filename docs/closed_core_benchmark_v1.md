# Closed Core Benchmark v1

## Purpose

This is a **development regression benchmark**, built from the already exposed
question bank. It certifies the factual chain:

```text
question → required original evidence → source relevance → answer
```

It is not a fresh holdout and must not be used to claim generalisation.

## Included

- DB/DC/IRP institutional facts
- tax rules and premise correction
- procedures and documents
- product factual fields: risk grade, fee, asset type, manager, effective date
- factual product comparison
- closed compound questions

## Excluded

- personalised product recommendation and suitability
- clarification, abstention, safe-response, and prompt-injection policy tests
- real-time or out-of-scope requests

Advisory and unsupported behaviour remain a separate policy benchmark. Future
fresh holdouts must report Closed Core and Advisory/Policy scores separately.
