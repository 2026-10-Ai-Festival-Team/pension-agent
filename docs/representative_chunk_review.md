# 대표 청크 감사 결과

## 검토 범위

- 전체 청크: 514개
- 검토 CSV 대상: 152개
- 1,500자 초과 청크: 37개
- 100자 미만 청크: 58개
- 표 청크 검토: 94개
- 상품 문서 청크 검토: 130개
- PPTX 청크 검토: 10개, XLSX 청크 검토: 7개

검토 CSV는 긴·매우 짧은 청크 전체와 형식·유형별 결정적 표본, 상품 청크 표본을 포함한다. CSV 자체는 원문 텍스트를 포함하므로 Git에 저장하지 않는다.

## 발견 사항과 조치

| 문제 유형 | 관찰 | 조치 |
|---|---:|---|
| 제목·표 제목 분리 가능성 | 표 직전 제목이 독립 문단으로 남을 수 있음 | 제목만 있는 버퍼는 다음 표 청크의 `section`, `text`, `element_ids`에 포함 |
| 너무 짧은 청크 | 58개 | 짧은 표 행·PPTX 제목·짧은 Q&A는 유효할 수 있어 자동 병합하지 않음 |
| 너무 긴 청크 | 37개 | 단일 원본 문단·표 행을 문자열 중간에서 자르지 않고 그대로 유지 |
| 표 헤더 | 표 청크 94개 표본 | 첫 비어 있지 않은 행을 헤더로 반복하는 현재 규칙을 유지하고, 다단 헤더는 전체 Corpus 전 재검토 |

## 유지한 예외

- 짧은 표 행·위험등급·Q&A 청크는 단독으로도 검색 근거가 될 수 있어 유지한다.
- 긴 단일 문단 또는 긴 표 행은 숫자·세율·문장 맥락 손상을 막기 위해 긴 청크 목록에서 수동 검토한다.
- OCR 보류 문서 `doc31.pdf`, `doc37.pdf`는 청크를 만들지 않는다.
