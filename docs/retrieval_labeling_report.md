# 검색 평가셋 근거 라벨링 보고서

## 범위와 방법

40개 질문을 10개씩 나누어 검토했다. 각 질문은 Simple·Kiwi BM25 Top-20 합집합을 우선 확인했고, 직접 근거가 누락되거나 질문 범위가 불명확한 경우에는 Corpus 문자열 검색과 관련 상품 투자설명서의 전체 청크를 추가로 확인했다.

관련도 `2`는 해당 청크만으로 질문에 답할 수 있는 직접 근거, `1`은 예외·세부 조건을 보완하는 근거다. 검색 순위와 BM25 점수는 관련도 판정에 사용하지 않았다.

## 결과

| 항목 | 수 |
|---|---:|
| 전체 질문 | 40 |
| 답변 가능 질문 | 38 |
| 답변 불가능 질문 | 2 |
| `dev` / `test` | 30 / 10 |
| `pending_label` 잔여 | 0 |
| OCR 의존 질문 | 0 |

답변 가능한 질문은 모두 하나 이상의 근거 청크를 갖고, 모든 `chunk_id`, `source_id`, `locator`를 현재 Corpus와 대조했다. 복합 근거가 필요한 R-002, R-024, R-036은 `evidence_requirement: "all"`로 기록했다. 나머지는 첫 BM25 기준선의 Hit@k와 호환되는 `"any"`다.

## 질문 수정

아래 질문은 정답 범위가 임의로 넓어지는 것을 막기 위해 라벨링 전에 좁혔다. 원래 문장은 특정 상품·비교 기준이 없어서 유효한 정답 청크를 고정할 수 없었다.

| 질문 ID | 수정 방향 |
|---|---|
| R-024 | 특정 상품코드의 투자대상·위험등급 확인 |
| R-025 | IRP에서 선택 가능한 상품 유형 확인 |
| R-026 | 특정 상품의 해외자산 환율변동위험 확인 |
| R-027 | 문서의 원리금보장·채권형 펀드 분류 확인 |
| R-028 | 특정 상품코드의 투자대상·전략 확인 |
| R-030 | 특정 상품코드의 수수료·총보수 표 확인 |
| R-032 | 특정 상품코드의 수수료·총보수 표 확인 |

수정 사실은 각 질문의 `notes`에 `question_revision:`으로 남겼다. 후보 수집 파일은 이 변경된 질문으로 다시 생성해야 한다.

## 답변 불가능 질문

- R-039: 개인 계좌 수익률은 제공 문서에 없다.
- R-040: 개인 상황과 미래 수익률 근거가 없으며, 단정적 금융상품 추천은 프로젝트 제약에도 맞지 않는다.

두 질문은 Recall·MRR 집계에서 제외하고, 이후 Agent의 한계 고지 동작을 점검하는 데 사용한다.
