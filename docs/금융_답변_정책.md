# 금융 답변 정책

## 목적

연금 Agent는 제공 문서에 근거한 일반 정보를 보수적으로 제공한다. 검색 보강 데이터는 검색어 확장과 용어 매핑에 활용할 수 있지만, 보강 데이터만으로 금융 사실을 확정하거나 최종 출처로 표시하지 않는다.

## 원천 provenance

모든 `ParsedDocument`, `SearchChunk`, `SearchResult`에는 다음 필드를 둔다.

| 필드 | 값 | 정책 |
|---|---|---|
| `source_type` | `original` / `augmented` | 원본과 보강 데이터를 구분한다. |
| `authority_level` | `primary` / `secondary` | 금융 사실 확정에 사용할 근거 권위를 나타낸다. |
| `as_of_date` | `YYYY-MM-DD` 또는 없음 | 원문에 확인 가능한 기준일을 보존한다. |

기본값은 `original`과 `primary`다. 기존 원본 Corpus도 이 기본값으로 해석된다. 최종 생성은 적어도 하나의 `original` + `primary` 근거가 있을 때만 허용하며, 보강 근거만 인용한 생성 결과는 Fail-Closed로 차단한다.

## 최종 답변 형식

성공 응답은 다음 구조를 사용한다.

```text
[답변]
문서 근거에 따른 답변

[근거]
- [출처: 원본 문서 경로, 페이지·슬라이드·시트, 기준일(있을 때), chunk_id]

[유의사항]
- 질의 유형에 맞는 보수적 안내
```

근거가 부족하거나 고객 조건이 부족하면 생성기를 호출하지 않고 `[답변]`, `[확인 필요]`, `[유의사항]`으로 한계를 안내한다.

## 금융·세무·법률성·추천 정책

- 세제 질문: 문서 기준의 일반 정보임을 알리고, 소득·계좌·수령 방식·적용 시점에 따른 차이를 안내한다.
- 법률성 질문: 법률 해석이나 권리 판단을 단정하지 않고 개별 사실관계 및 전문가 확인 필요성을 알린다.
- 상품 비교: 위험등급·보수·투자대상 등 원문에 있는 항목만 비교한다.
- 상품 추천: 투자 기간, 위험 성향, 운용 목적이 없으면 특정 상품을 추천하지 않고 확인 질문을 한다. 조건이 있어도 “가장 좋은 상품”으로 단정하지 않으며 최종 판단은 사용자가 한다.
- 원본 근거 없음: 답을 추정하지 않고 제공 문서 범위에서 확인할 수 없다고 안내한다.

## 적용 범위

이 정책은 기본 `PensionAgent` 경로에 적용한다. P24-B의 requirement별 retrieval·matcher 실험 경로는 별도 검증 전 기본 경로에 포함하지 않는다.
